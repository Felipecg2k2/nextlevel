# NextLevel — Escola de Tecnologia

## Desenvolvedor
**Felipe Cunha Guedes**

## Objetivo
Landing Page institucional para a NextLevel, uma escola fictícia de tecnologia. O projeto tem como objetivo apresentar a instituição, seus cursos, diferenciais e formas de contato, com foco em jovens interessados na área de tecnologia.

## Tecnologias
- HTML5
- CSS3
- Google Fonts (Poppins)

Não foram utilizados JavaScript, frameworks ou templates prontos.
